# Credit Scoring

Предсказание вероятности дефолта клиента по кредиту.

## Задача

Бинарная классификация: предсказать, уйдёт ли клиент в дефолт в ближайшие 2 года, на основе его кредитной истории.

## Данные

**Credit Scoring Dataset** — 104 805 записей, 12 признаков.

- Использование кредитного лимита
- Возраст
- Просрочки (30–59, 60–89, 90+ дней)
- Коэффициент долга
- Ежемесячный доход
- Количество открытых кредитов
- Кредиты на недвижимость
- Иждивенцы

Целевая переменная: `SeriousDlqin2yrs` — дефолт за 2 года.

## Подход

1. **EDA:** анализ распределений, выявление дисбаланса классов (6.63% дефолтов).
2. **Предобработка:** заполнение пропусков медианой, клиппинг выбросов по 1–99 перцентилям.
3. **Feature Engineering:** сумма просрочек, флаг превышения лимита, логарифм дохода.
4. **Модели:** Logistic Regression (baseline), Random Forest, HistGradientBoosting.
5. **Тюнинг:** GridSearchCV + подбор порога классификации.

## Результаты

| Метрика | Значение |
|---------|----------|
| ROC-AUC | 0.8656 |
| Gini | 0.7312 |
| F1-score | 0.4426 |

Ключевые факторы риска: сумма просрочек, использование кредитного лимита.
