# Кредитный скоринг: предсказание дефолтов заёмщиков

## Описание проекта

Данный проект решает задачу бинарной классификации: по финансовым и кредитным характеристикам клиента необходимо предсказать вероятность серьёзной просрочки (дефолта) по кредиту в течение двух лет.  
Проект включает полный цикл работы с данными: предварительный анализ, очистку, генерацию признаков, построение базовой и продвинутой моделей, сравнение метрик и интерпретацию результатов.

## Данные

Используется публичный датасет **Give Me Some Credit** с платформы Kaggle.  
Исходные файлы: `train.csv`, `test.csv`.

Целевая переменная — `SeriousDlqin2yrs` (в проекте переименована в `Дефолт_за_2_года`):  
- `1` — заёмщик допустил серьёзную просрочку/дефолт,  
- `0` — дефолта не было.

Характеристики набора:
- 104 805 записей в обучающей выборке, 12 исходных признаков;
- дисбаланс классов: ~6,6% положительного класса;
- пропуски в признаках `Ежемесячный_доход` и `Иждивенцы`;
- выбросы в финансовых показателях.

## Основные этапы

1. **EDA**  
   Анализ распределений, пропусков, выбросов, корреляций.

2. **Предобработка**  
   - заполнение пропусков медианой;  
   - винзоризация по 1-му и 99-му процентилям;  
   - стратифицированное разделение на обучающую (80%) и валидационную (20%) выборки.

3. **Feature Engineering**  
   Созданы дополнительные признаки:  
   - суммарное количество просрочек;  
   - бинарные флаги наличия просрочек;  
   - флаг использования кредитного лимита выше 50%;  
   - логарифм дохода;  
   - возрастные флаги;  
   - флаг наличия иждивенцев.

4. **Модели**  
   - Baseline: логистическая регрессия с RobustScaler;  
   - Random Forest;  
   - HistGradientBoosting (без балансировки, с балансировкой, с подбором порога).

5. **Оценка качества**  
   Рассчитаны метрики: Accuracy, Precision, Recall, F1-Score, ROC-AUC, PR-AUC, Gini.  
   Построены ROC-кривые, матрицы ошибок, график важности признаков.

## Результаты

Сравнение ключевых метрик на валидационной выборке:

| Модель | ROC-AUC | F1-Score |
|--------|---------|----------|
| Baseline (логистическая регрессия) | 0.8559 | 0.2911 |
| Random Forest | 0.8414 | 0.2500 |
| Gradient Boosting | 0.8637 | 0.2887 |
| Gradient Boosting + class_weight | 0.8642 | 0.3412 |
| **Gradient Boosting + class_weight + tuned threshold** | **0.8642** | **0.4426** |

Итоговая модель превосходит Baseline по F1-Score более чем на 0.15 при сохранении высокого ROC-AUC.
